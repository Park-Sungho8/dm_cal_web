# The More (더모아)

엔화 결제를 자주 하는 사람을 위한 **환율 · 합산 계산기**입니다.
서버나 데이터베이스가 없는 **순수 정적 웹앱(PWA)** 으로, 모든 계산은 브라우저 안에서 이뤄지고
저장은 브라우저 `localStorage`를 사용합니다. 아이폰 Safari에서 **"홈 화면에 추가"** 하면
아이콘이 생기고 주소창 없는 전체화면 앱처럼 동작합니다.

다크 테마로, 주로 **iPhone 16 Pro의 Safari**에서 한 손으로 쓰는 상황을 염두에 두고 디자인했습니다.

> 원래 SwiftUI 앱 `dm_cal`을 웹으로 이식한 버전입니다.
> 기존 사이드로딩 방식은 인증서/프로비저닝 재서명이 주기적으로 필요했지만,
> 웹앱은 한 번 호스팅해두면 갱신 없이 계속 쓸 수 있습니다.

## 기능

- **환율 계산** — `(금액A − 금액B) / 결제금액` = `¥/₩`. **저장** 버튼으로 환율을 보관합니다.
  - **수동**: 직접 입력해 계산 후 저장
  - **실시간**: `불러오기`로 엔→원 환율을 자동 조회 후 저장
  - 마지막에 저장한 값이 합산 계산에 쓰입니다.
- **합산 계산** — 숫자 키패드로 금액을 더하고, 저장된 환율을 곱해 원화 합계를 표시합니다.
  `999`로 끝나는 임계값 4개까지 도달에 필요한 엔(¥)도 함께 계산합니다.
  키패드 우측 하단의 **C** 버튼으로 입력한 목록을 초기화합니다.

## 참고

- **저장 데이터는 기기(브라우저)별로 보관**됩니다. 기존 iOS 앱과 동일하게 단일 기기용이며,
  Safari 데이터를 완전히 지우면 저장값이 사라집니다.
- **실시간 환율**은 `open.er-api.com`(무료 · 키 불필요 · CORS 허용)을 사용합니다.
  인터넷이 없으면 실시간 조회만 안 되고, 나머지(수동 환율 · 합산)는 오프라인에서도 동작합니다.
- **홈 화면 아이콘**은 iOS가 "추가" 시점에 캐싱하므로, 아이콘을 바꾼 뒤에는
  홈 화면에서 한 번 **삭제 후 다시 추가**해야 새 아이콘이 반영됩니다.
